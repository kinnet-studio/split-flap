# Flap sounds

The examples app's default sound: twelve single flaps cut from "Split Flap
Display" (Pixabay sound 58766, uploaded by the freesound_community account).
Each file is one flap landing and its rattle (50–70 ms), with the room rumble
filtered out (150 Hz high-pass), a 0.3 ms fade-in, an 8 ms fade-out and the
peak normalized to 0.9.

They are used only by the examples app; the published package ships `dist/`
alone and does not include them. Check the source page's licence before
reusing them elsewhere.
