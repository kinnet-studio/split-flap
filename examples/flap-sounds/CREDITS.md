# Flap sounds

The examples app's default sound: twelve single flaps cut from "Split Flap
Display" by ngruber on Freesound, <https://freesound.org/s/261244/>.

License: Creative Commons 0
(<https://creativecommons.org/publicdomain/zero/1.0/>).

Each file is one flap landing and its rattle (55–70 ms) from the original
44.1 kHz recording, mixed to mono, with the room rumble filtered out (150 Hz
high-pass), a 0.3 ms fade-in, an 8 ms fade-out and the peak normalized to 0.9.

They are used only by the examples app; the published package ships `dist/`
alone and does not include them.
